# v0.4.1

Released 29 October 2026 · Tag `v0.4.1` · Branch `release/v0.4.1`

A small fix to the Home screen.

## Fixed

- **Home heading.** The section for the classic puzzle on Home is titled "Knight's Tour" again, instead of showing the app name.

## Updating

If you've opened the game since v0.4.0, you'll see "A new version is available." Tap **Reload** to get this fix.

## For developers

- The heading in `src/screens/home.js` is now fixed text rather than `app.tourModeName`, so it no longer changes with `app.config.js`.
- v0.4.0 was tagged before this change was committed, so it reached the site only with this release. Commit everything before tagging: only the tagged commit is deployed.
