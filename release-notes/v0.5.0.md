# v0.5.0

Released 29 October 2026 · Tag `v0.5.0` · Branch `release/v0.5.0`

Share every game, not just perfect ones.

## What's new

- **See result when you get stuck.** The "No moves left" message on the board now has a **See result** button. Undo and Restart still work as before.
- **Result screen for any finished game.** It shows how many squares you covered, where you started and ended, your time and undos, and your best for that board size ("That's your best on 8×8", or "Your best on 8×8 is 52").
- **Share any game.** The share card and message work for unfinished games too: "Visited 23 of 64 squares in 4:08." Squares you never reached stay dark on the card.
- **Squares on the card.** The share card's stats now start with the squares covered, for example `23/64`.
- **One name for the puzzle.** The Play and Result screens are titled "Knight's Tour", the same as its heading on Home. The app itself is still called Knight Zigg.
- **Fresh install screenshots.** The screenshots in Android's install dialog match the app again.

## For developers

- `shareData()` and `renderResult()` handle both outcomes (`won` and `stuck`); the result and share routes open for either.
- The card's stats row is built once (`cardStats`) and used by both the on-screen card and the shared image.
- New tests in `tests/share.test.js` (66 tests in total).
- `tourModeName` in `app.config.js` is now "Knight's Tour", and the Home heading reads it again instead of fixed text, so one setting names the puzzle everywhere.
- `release-notes/v0.4.1.md` rewritten to describe that release's actual change.
