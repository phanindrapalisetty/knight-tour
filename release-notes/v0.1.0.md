# v0.1.0

Released 29 October 2026 · Tag `v0.1.0`

The first versioned release. The game has been rebuilt to run entirely on your device, with a new design and the features below. It runs in the browser today and is ready to be packaged as Android and iOS apps.

## What's new

- **New design.** Home, Play, Result and Share screens.
- **Board sizes.** Play on 5×5, 6×6, 7×7 or 8×8.
- **Timed mode.** A live clock and a best time to beat for each board size.
- **Day streak.** Finish a game each day to grow it, and see the current week at a glance.
- **Stats.** Best score, best time, games played and tours completed for each board size.
- **Results and sharing.** After a full tour, see your time and undos, then share a result card as text or an image.
- **Themes.** Five board themes (Tournament, Walnut, Midnight, Marble, Rose), each in light and dark, with a System / Light / Dark setting.
- **Your game is saved.** Close the app and pick up where you left off. If it's open in two tabs, both stay up to date.
- **New app icon.** A closed knight's tour.

## Fixed

- Everyone playing at the same time shared one board, so moves from different players mixed together.

## Known limitations

- The daily puzzle is a placeholder; it isn't playable yet.
- Hints are built but switched off for now.
- The app needs a connection to open; offline play comes with the PWA work.
- Android and iOS apps aren't available yet.

## For developers

- The Python (FastAPI) server, Jinja template and Dockerfile are removed; the game logic now runs in JavaScript.
- Built with Vite and tested with Vitest (60 tests). Requires Node.js 22.12 or later.
- App name and brand colors live in `app.config.js`, and the PWA manifest is generated from it.
- Feature switches live in `src/features.js`.
- Saved data is versioned, and older formats upgrade automatically when loaded.
