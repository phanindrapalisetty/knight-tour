# v0.3.0

Released 29 October 2026 · Tag `v0.3.0` · Branch `release/v0.3.0`

The game is now online, and every release is checked, published and deployed automatically.

## What's new

- **Play it on the web.** The game is live at https://phanindrapalisetty.github.io/knight-tour/, and it can be installed to your home screen from there.
- **Release pages.** Each version now has a GitHub Release with its notes.

## For developers

- **CI** (`.github/workflows/ci.yml`): tests, a production build and release checks run on every push to `main` and `release/**`, and on pull requests.
- **Release checks** (`scripts/check-release.mjs`): on `release/vX.Y.Z` branches and `vX.Y.Z` tags, `package.json` must have version `X.Y.Z` and `release-notes/vX.Y.Z.md` must exist and not be empty.
- **CD** (`.github/workflows/release.yml`): pushing a `vX.Y.Z` tag runs the tests and checks, creates the GitHub Release from these notes, and deploys to GitHub Pages. It can also be run by hand from the Actions tab.
- **Sub-path builds**: `BASE_PATH` sets where the site is served from. Pages builds use `/knight-tour/`; local and native builds keep `/`. The manifest, icons and service worker follow it.
- **`main` is protected**: a ruleset requires the `tests` check, keeps history linear, and blocks deletion and force pushes.
- README: CI badge, live link, CI/CD overview and the updated release steps.
- Roadmap: CI/CD added under Housekeeping; the old CI item in Phase 6 removed.

## Known limitations

- Offline play isn't there yet; that's the next release (Phase 4).
- Android and iOS builds in CI wait for those apps.
